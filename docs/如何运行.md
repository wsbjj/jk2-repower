# 怎么运行

三种用法，从简单到自动化。

---

## 前置条件（已确认你的机器满足）

- Mac 和宿舍在同一位置（**蓝牙必须能覆盖到设备，约 10 米**）
- Python 3 + bleak（已装好，`bleak 3.1.0`）
- 蓝牙权限（已验证可以扫描）

项目路径：`~/代码/pj`

---

## 方式一：双击运行（最简单）

打开项目文件夹，双击：

| 文件 | 作用 |
|---|---|
| `查看状态.command` | 看电压、电流、开关、供电时段 |
| `启动守护.command` | 常驻，断电自动复电 |

> 第一次双击如果提示"无法打开"，右键 → 打开 → 仍要打开。

`启动守护.command` 会占用一个终端窗口，**关掉窗口就停止**。

---

## 方式二：终端命令

```bash
cd ~/代码/pj

./run.sh jk-status      # 查状态
./run.sh jk-recover     # 复电一次
./run.sh jk-watch       # 守护模式（前台，Ctrl-C 退出）
```

或者不用 run.sh：

```bash
python3 ble/jk2.py status
python3 ble/jk2.py recover
python3 ble/jk2.py watch --interval 60
```

换房间：加 `--token B03-XXXX`（设备名就是令牌）。

**单次执行大约 10 秒**（扫描设备占大部分），之后有地址缓存会快很多。

---

## 方式三：开机自启（真正的全自动）

装成 launchd 服务，**登录就自动跑，崩了自动重启，不用管**。

```bash
cp ~/代码/pj/launchd.example/com.dorm.jk2.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.dorm.jk2.plist
```

检查是否在跑：

```bash
launchctl list | grep jk2
```

看日志：

```bash
tail -f ~/代码/pj/private/logs/jk2.log
```

停止 / 卸载：

```bash
launchctl unload ~/Library/LaunchAgents/com.dorm.jk2.plist
rm ~/Library/LaunchAgents/com.dorm.jk2.plist
```

> 注意：launchd 后台进程需要蓝牙权限。如果日志里报扫描失败，
> 去 系统设置 → 隐私与安全性 → 蓝牙，确认终端 / python 有权限。

## 常见问题

**「扫描 B03-XXXX …」卡很久然后「未找到」**

- 距离太远。设备在宿舍，Mac 要放在附近
- 手机连着这个设备时 Mac 可能连不上，先把手机微信退掉
- 蓝牙关了，或者权限没给

**「开关 关」但实际有电**

字段 24/25/26 的精确含义还没完全对上（有一项可能是反相）。
以电压/电流读数为准：`电压 > 200V` 且 `电流 > 0` 就是通电。

**想让 Mac 合盖也继续跑**

系统设置 → 电池 / 电源适配器 → 关闭「自动睡眠」。
或者用 `caffeinate -s` 常驻。

**换宿舍 / 换房间**

改 `DEV_TOKEN` 环境变量即可：

```bash
DEV_TOKEN=B03-XXXX ./run.sh jk-status
```

## 原理速记

```
Mac ──BLE──> JK-2（设备名 B03-XXXX，服务 ffe0，特征 ffe1）
              ↑
              └── 写入顺序：
                  1. 明文配置串（云端 getCurrentRPCStr）
                  2. 加密 RPC（云端 getCurrentRPCStr_B03.08）← 真正的指令
```

云端接口用设备令牌即可，不需要登录：
`https://thingsboard.example.com:8080/api/v1/B03-XXXX/...`
