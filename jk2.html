JK-2 宿舍复电

Web Bluetooth · 无需安装 · 数据只在你本机
当前浏览器不支持 Web Bluetooth
请用 Chrome / Edge 打开，并且必须通过 http://localhost 访问 （Safari 不支持，file:// 直接打开也不行）。

在项目目录执行：
python3 -m http.server 8080
然后打开 http://localhost:8080/jk2.html
第一次点按钮会弹出蓝牙选择框，选 B03-xxxx 那个。 之后浏览器会记住授权，不再弹窗。
