# 多宿舍使用

每个宿舍一台 JK-2，设备令牌 = 设备名 = `B03-<房间号>`。
一个 Mac 可以同时管多台，**只要蓝牙能扫到**。

---

## 一、先把宿舍加进配置

```bash
cd ~/代码/pj

./run.sh jk-add B03-XXXX 我的宿舍
./run.sh jk-add B03-XXXX 隔壁老王
./run.sh jk-add B03-XXXX 三楼
```

看列表：

```bash
./run.sh jk-rooms
```

配置文件在 `private/devices/devices.json`，也可以直接编辑：

```json
[
  { "token": "B03-XXXX", "name": "我的宿舍" },
  { "token": "B03-XXXX", "name": "隔壁老王" },
  { "token": "B03-XXXX", "name": "三楼" }
]
```

**RSSI 对照：**

| RSSI | 能不能用 |
|---|---|
| > -70 | 稳，秒连 |
| -70 ~ -80 | 可以，稍慢 |
| -80 ~ -90 | 勉强，容易失败重试 |
| < -90 | 基本没戏，别加 |

## 三、批量操作

```bash
./run.sh jk-status-all     # 全部查状态
./run.sh jk-recover-all    # 全部复电
```

## 四、关于「在别的设备上登录」

这套方案**根本不需要登录**，所以不存在账号问题：

- 云端用的是**设备令牌**（`/api/v1/B03-XXXX/...`），公开接口，不带账号密码
- 蓝牙是本地直连，跟账号无关

所以只要换台机器跑，改一下配置就行。

### 换机器要做什么

1. 把 `portable/` 整个文件夹拷过去
2. 装 Python 3
3. `bash install.sh`
4. 编辑 `private/devices/devices.json` 加上宿舍

`portable/` 是自包含的，只有 **一个依赖：bleak**，macOS / Linux / Windows / 树莓派都能跑。

```bash
# 树莓派 / Linux
cd portable
bash install.sh
python3 jk2.py watch --all
```

### 各平台的现实情况

| 设备 | 能不能跑 | 说明 |
|---|---|---|
| **树莓派 Zero 2 W** | ✅ 最佳 | ¥100 左右，7×24 常驻，功耗 1W |
| 旧笔记本 / 旧 Mac | ✅ | 装个 Linux 或直接用 macOS |
| Windows 台式机 | ✅ | 蓝牙适配器要支持 BLE 4.0+ |
| 另一台 Mac | ✅ | 现成的 |
| **iPhone** | ❌ | 后台不能跑 BLE 脚本，小程序也不能自动化 |
| **安卓手机** | ⚠️ | Termux 里 BLE 很难搞，不推荐 |
| 路由器（OpenWrt） | ❌ | 一般没有 BLE |

## 五、关键限制：蓝牙范围

**一台设备只能覆盖约 10 米（隔一堵墙更短）。**

所以：

- 同一层、相邻几间 → 一台 Mac 能全管
- 隔楼层 / 隔栋 → 扫不到，管不了
- 要管远处宿舍 → 那间屋子里得放一台设备

这也是为什么不能做「云端定时复电」——
JK-2 是纯 BLE 设备，没有 WiFi，云端下不去指令。
云端只能存配置，指令必须有人（Mac/树莓派）在跟前发。

---

## 六、多设备守护的注意点

1. **一次只能连一台**。BLE 是点对点，`watch --all` 是串行轮询的。
2. **轮询间隔要拉开**。3 台设备建议 `--interval 120`，别 30 秒一轮，太吵。
3. **某一台连不上不影响其他台**，脚本会跳过继续。
4. 设备被手机微信占用时会连不上，等一会儿会自己好。
