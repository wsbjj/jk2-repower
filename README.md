# 高卫智能用电监控器（JK-2）自动复电工具

通过蓝牙连接 JK-2，获取设备状态并尝试复电；支持命令行、网页版和定时运行。默认云端地址为 `https://www.myneepu.com:8080`，可通过 `JK2_BASE` 覆盖。

项目记录过特定环境下的使用情况；本次修改仅通过本地模拟验证，不能保证所有设备、学校网络或服务器部署均兼容。

## 开箱即用：macOS 命令行

准备一台带蓝牙、能联网的 Mac，以及设备二维码下方的设备码（如 `B03-` 后接数字）。电脑需要位于设备蓝牙范围内；操作前关闭可能占用设备蓝牙连接的手机小程序。此流程需要 Python 3.10 以上及 Git，运行本地自测还需要 Node.js 18 以上。抓包、越狱、管理平台账号和 `mitmproxy` 均非此流程的前置条件。

### 1. 下载并安装依赖

```bash
git clone https://github.com/wsbjj/jk2-repower.git
cd jk2-repower
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r portable/requirements.txt
```

macOS 首次连接时，请在系统设置中允许终端或 Python 使用蓝牙。之后每次打开新终端，先进入项目目录并执行 `source .venv/bin/activate`。

### 2. 添加设备

将下面的 `B03-你的设备数字` 替换成自己设备上的**完整设备码**；占位文字不能直接使用。

```bash
./run.sh jk-add B03-你的设备数字 我的宿舍
./run.sh jk-rooms
```

设备码会写入本机 `private/devices/devices.json`，该目录被 Git 忽略。首次安装使用默认云端地址，无需填写域名或 appid。

### 3. 复电并查看结果

```bash
./run.sh jk-recover
```

程序会从云端获取指令、通过蓝牙写入设备，然后显示收到的状态。输出 `已通电` 表示收到的状态报告开关已打开；如果没有收到状态，按[常见问题](#常见问题)排查。

> **设备写入提示：** `jk-status` 和 `jk-recover` 当前使用相同的 BLE 指令交互；查询状态也会向设备写入指令，不能视为纯读取。默认两次写入之间至少间隔 600 秒，短时间内连续操作会被跳过。项目曾观察到频繁写入后出现故障码 24；请优先按需单次操作。

### 4. 按需启用自动监控

```bash
./run.sh jk-watch
```

确认终端中的风险提示后开始运行；默认每 600 秒轮询设备，过程中会写入指令。保持电脑运行、联网、蓝牙开启且终端窗口打开；按 `Ctrl+C` 停止。此模式不是只读监控，不保证断电后一定能恢复供电。

## 其他使用方式

### 网页版

在 macOS 上运行 `./run.sh web`，或双击 `打开网页版.command`；在 Chrome 或 Edge 中按页面提示选择设备。首次连接需要授权蓝牙，页面关闭后监控停止。网页通过本机服务器打开，并需要网络、蓝牙及服务器允许浏览器跨域访问。

**网页版守护当前每 60 秒写一次设备**，比命令行更频繁；请先阅读页面中的风险提示和[故障码记录](docs/故障码24-时钟异常.md)。

### macOS 定时复电

需要先设置 `private/local.env` 中的 `DEV_TOKEN`，再执行：

```bash
mkdir -p private
cp -n local.env.example private/local.env
# 编辑 private/local.env，把 DEV_TOKEN 改为自己的完整设备码
./run.sh install-daily
```

默认每天 06:00、22:00 各运行一次；可用 `./run.sh uninstall-daily` 卸载。安装时请保持本节第一步创建的虚拟环境已激活，电脑需在运行时具备网络和蓝牙连接。定时任务可能因睡眠、权限或设备连接失败而未执行。

### 本地模拟自测

```bash
./run.sh test
```

模拟自测不连接真实设备，仅验证本地模拟服务及客户端相关流程。更多用法见 [完整技术教程](docs/完整技术教程.md)。

## 配置与隐私

- 默认服务器为 `https://www.myneepu.com:8080`；如部署不同，可将 `JK2_BASE="https://你的服务器:8080"` 写入 `private/local.env`。直接运行 Python 脚本时可通过环境变量设置；网页版通过浏览器 `localStorage` 的 `jk2.base` 覆盖。
- `private/` 用于保存本机设备码、令牌、抓包及状态，不会被正常 `git add` 纳入；不要将这些信息发布到公开仓库。
- 如果同时设置 `DEV_TOKEN` 和设备列表，`jk-status`、`jk-recover` 优先使用 `DEV_TOKEN`；`jk-watch` 使用设备列表。
- 云端账号管理功能需要额外的 ThingsBoard 账号和权限，不属于设备码快速流程。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 找不到蓝牙设备 | 确认设备通电、距离足够近，关闭其他占用连接的客户端，并检查系统蓝牙权限。 |
| 云端取指令失败 | 检查网络、设备码和服务器地址；默认地址不代表所有网络都可访问。 |
| 提示保护阈值、跳过写入 | 等待默认的 600 秒写入间隔；不要通过缩短间隔绕过保护。 |
| 未收到状态或复电失败 | 确认设备及服务端兼容，查看终端日志；不要把未收到回报当作成功。 |
